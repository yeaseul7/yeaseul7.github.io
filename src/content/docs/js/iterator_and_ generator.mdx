### 왜 비동기 이터레이션이 필요한가

> 일반 이터레이터는 값이 즉시 준비되어 있다는 전제로 동작한다. 하지만 네트워크 요청처럼 다음 값이 언제 준비될지 모르는 상황에서는 비동기 이터레이션이 필요하다.

```javascript
// 일반 이터레이터

const range = {
  from: 1,
  to: 3,

  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;

    return {
      next() {
        if (current <= last) {
          return {
            value: current++,
            done: false,
          };
        }

        return {
          done: true,
        };
      },
    };
  },
};
```
