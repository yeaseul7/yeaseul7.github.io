# Riot Games: 게임 기획의 3가지 핵심

게임 기획에 대해 공부하다가 Riot Games의 R&D 관련 글을 읽게 됐다.

Riot Games에서는 게임을 개발하기 전 **Opportunity, Thesis, Audience** 세 가지를 중요하게 생각한다고 한다.

쉽게 말하면 어떤 게임을 왜 만들고, 누구에게 제공할 것인지 정하는 과정이다.

## 1. Opportunity: 시장 기회

기존 게임의 부족한 점이나 아직 충족되지 않은 플레이어의 욕구를 찾는 단계다.

Riot Games에서는 두 가지 접근법을 소개한다.

| 구분       | 설명                                       | 예시                                |
| ---------- | ------------------------------------------ | ----------------------------------- |
| Inside-out | 기존 게임을 개선하고 발전시키는 방식       | DOTA → LoL                          |
| Outside-in | 시장이나 플레이어의 욕구에서 출발하는 방식 | 창작 욕구 → 레고와 비슷한 게임 경험 |

게임을 기획할 때는 이런 질문을 해볼 수 있다.

- 어떤 플레이어가 이 게임을 좋아할까?
- 기존 게임에서 아쉬운 점은 무엇일까?
- 굳이 새로운 게임을 만들 이유가 있을까?

## 2. Thesis: 성공 가설

발견한 기회를 어떤 방식으로 게임에 적용할지 정하는 단계다.

단순히 재미있을 것 같다는 생각보다 기존 게임과 무엇이 다르고, 왜 플레이어가 좋아할 것인지 설명할 수 있어야 한다.

- 해결하려는 문제
- 기존 게임과의 차별점
- 핵심 시스템
- 검증이 필요한 가설
- 개발하지 않을 기능

특히 인상적이었던 부분은 **무엇을 만들지 않을지도 정해야 한다**는 점이다.

이것저것 기능을 추가하다 보면 정작 게임에서 중요한 재미가 무엇인지 흐려질 수 있기 때문이다.

## 3. Audience: 타깃 플레이어

게임을 누구에게 제공할지 정하는 단계다.

단순히 나이나 성별로 구분하기보다는 플레이어가 원하는 경험, 플레이 환경, 기존에 즐기는 게임 등을 고려한다.

Riot Games에서는 타깃을 크게 세 가지로 구분한다.

| 구분              | 의미                                     |
| ----------------- | ---------------------------------------- |
| Core Audience     | 반드시 만족시켜야 할 핵심 플레이어       |
| Growth Audience   | 적절한 설계로 유입할 수 있는 플레이어    |
| Breakout Audience | 흥행에 따라 추가 유입될 수 있는 플레이어 |

### 1인 개발이라면?

혼자 개발하는 입장에서는 모든 플레이어를 만족시키기 어렵다.

그래서 초기에는 Core Audience에 집중하고, Growth Audience는 여유가 있을 때 고려하는 편이 현실적일 것 같다.

Breakout Audience까지 처음부터 고려하면 개발 범위만 커질 수 있다.

물론 핵심 타깃을 정했다고 실제 수요가 있는 것은 아니므로 플레이어 테스트는 필요하다.

## 정리

게임을 만들 때 재미있는 아이디어가 떠오르면 바로 개발부터 시작하는 경우가 많았다.

그런데 이번 글을 읽고 나니 개발에 들어가기 전에 최소한 세 가지는 정리해 두는 게 좋겠다는 생각이 들었다.

- **Opportunity:** 왜 이 게임을 만들어야 할까?
- **Thesis:** 기존 게임과 무엇이 다를까?
- **Audience:** 누가 이 게임을 좋아할까?

거창한 기획서를 작성하지 않더라도 이 정도는 정리하고 개발을 시작해 보려고 한다.
