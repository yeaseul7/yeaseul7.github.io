### React의 컴포넌트

react의 컴포넌트는 
브라우저에서 js 파일을 이용해서 컴포넌트를 실행합니다.

```
JavaScript 번들 다운로드
        ↓
JavaScript 실행
        ↓
React 컴포넌트 실행
        ↓
React Element Tree 생성
        ↓
실제 DOM에 반영
        ↓
브라우저 화면 렌더링
        ↓
사용자 이벤트 처리
```

### 서버 컴포넌트(Server Component)

서버 컴포넌트란 **서버 환경에서 실행되는 컴포넌트**입니다.

기존의 클라이언트 컴포넌트는 JavaScript를 브라우저로 전달하고 UI를 구성합니다.<br/>
하지만 컴포넌트가 브라우저에서 실행될 필요는 없습니다.

예를 들어서 서버에서 받아온 상품 목록을 단순히 보여주는 컴포넌트를 생각해보면

```tsx
function ProductList({ products }) {
  return (
    <ul>
      {products.map((product) => (
        <li key={product.id}>{product.name}</li>
      ))}
    </ul>
  );
}
```

이 컴포넌트는 사용자 이벤트 없이 데이터만 보여줍니다.

브라우저에서 실행한다면 해당 컴포넌트를 실행하기 위한 JavaScript를 다운로드하고 파싱하고 실행해야 합니다.

Server Component는 이것을 **서버에서 먼저 수행**합니다.

```text
서버
  ↓
데이터 조회
  ↓
Server Component 실행
  ↓
UI에 필요한 결과 생성
  ↓
브라우저로 전달
```

데이터베이스나 API에서 데이터를 조회한 뒤 바로 UI를 구성합니다.<br/>
그리고 해당 코드는 클라이언트 번들에 포함되지 않습니다.

그러면 브라우저가 다운로드하고 실행해야 하는 JavaScript의 양을 줄일 수 있습니다.

> **컴포넌트 실행 위치를 서버로 옮긴 것.**

주의할 것은 모든 컴포넌트를 Server Component로 만들 수 있는 것은 아닙니다. <br/>
`useState`, `onClick`같은 상호작용해야 하는 부분은 Client Component가 담당해야 합니다.
